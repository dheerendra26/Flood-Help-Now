# 🌊 Flood Help Now

**Flood Help Now** is a static informational website dedicated to spreading awareness and providing practical guidance on handling critical environmental challenges, with a primary focus on floods.

The platform publishes easy-to-understand articles that help individuals, students, and communities learn how to prepare for, respond to, and recover from flood-related situations.

---

## 🔍 Overview

Floods are among the most common and destructive natural disasters. This project aims to educate users by sharing well-structured articles that explain:
- Causes and impacts of floods  
- Safety measures before, during, and after floods  
- Environmental and social consequences  
- Preventive actions and awareness tips  

---

## ✨ Features

- Clean and responsive static website  
- Informative articles on environmental challenges  
- Simple navigation and user-friendly layout  
- Fast loading with no backend dependency
